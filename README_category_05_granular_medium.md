# Category 05 — 球撞击颗粒介质 (Ball into granular medium)

生成 1000 条「球落入沙堆/撞击颗粒介质」数据，每条含 2 视角 RGB 视频
（Side + Top，960×540）。

## 覆盖的子变体（`seed % 6` 分区）

- **落入沙堆**：从 0.2–0.8 m 高处落入沙堆。
- **表面反弹**：低速、高恢复系数，球在表面弹起。
- **浅层嵌入**：中速，球嵌入沙堆浅层。
- **完全掩埋**：高速/大球，球完全埋入。
- **形成冲击坑**：高速撞击，形成可见冲击坑。
- **引发颗粒飞溅**：极高速度，颗粒向外飞溅。

## 沙堆

300–600 粒小圆球（r=0.012–0.02 m）按错位六方密排晶格叠成截锥堆在
0.5 m 方盘内，球间距 2.2×r 保证初始无重叠。沙粒 `record=False`：被 PhysX
模拟但**不逐粒采集状态**，避免数百个 tensor view。只记录主球。

## 生成

```bash
uv run python scripts/generate_high_throughput.py \
  --config configs/category_05_granular_medium.yaml \
  --num-episodes 1000 --device cuda:0 2>&1 | tee logs/cat05.log
```

240 Hz 物理（`dt=1/240`），2 相机，960×540。

## 参数

| 量 | 范围 |
|---|---|
| 沙粒半径 | 0.012–0.02 m |
| 沙粒数量 | 300–600 |
| 球半径 | 0.03–0.05 m |
| 球质量 | 0.3–2 kg |
| 落高 | 0.1–0.8 m |
| 撞击速度 | 0–9 m/s |
